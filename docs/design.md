# 多网关与自动恢复设计

日期：2026-10-31。用户已确认实施。System；当前没有 .ai_state，不自动初始化项目状态。

## 动机和范围
创建的远端代理失效后，外部软件继续使用固定本地地址；允许多个端口分别绑定国家，HTTP 与 SOCKS5 共用每个网关端口。提供本地 Web 管理，并修复国家展示截断和统计口径混用。

## 验收
- AC1: 每个自定义 TCP 端口同时接受 HTTP 请求、HTTP CONNECT 和 SOCKS5 CONNECT；域名交给上游解析；端口冲突明确报错。
- AC2: 多网关独立绑定国家 location_id 或 best；启停、更改绑定、重建、删除互不影响；无可用同国节点时不静默换国家。
- AC3: 端到端健康检查、防抖、退避；先创建并验证候选，再原子换线，延迟回收本工具拥有的旧实例；失败不形成无限创建风暴。
- AC4: 国家来自 provider-locations，返回所有国家、来源和刷新时间；缓存过期可见，不混入 map 汇总；CLI 无 20/25 截断。
- AC5: 中文 Web 控制台实现多网关 CRUD、启停/检查/换线、国家搜索、凭据更新、配额、事件日志、复制地址；离线静态资源，无 CDN/Node 构建依赖。
- AC6: 配置原子持久化、重启恢复，凭据不出现在 API/日志/网关文件；默认只绑定回环地址，管理 API 认证并抵御跨站写入。
- AC7: 单测和真实本地 socket/API 集成测试通过；原 CLI 和配置兼容；用户 config.json 字节保持不变。

## 切片
1. 官方位置数据与可靠协议探测（可独立验收 AC4）。
2. 混合代理端口、多网关、恢复及持久化（AC1–3、AC6）。
3. 管理 API、界面、启动脚本、文档和端到端验证（AC5、AC7）。

## 技术边界
Python 标准库 asyncio 数据面与 ThreadingHTTPServer 回环管理面；单进程唯一管理器。SOCKS5 CONNECT TCP，HTTP CONNECT 可访问 HTTPS；HTTPS 加密的代理监听和 UDP/BIND 不在已确认 HTTP/SOCKS5 范围。所有网关默认回环；局域网开放必须显式配置本地鉴权。配置与本地凭据分离。

新上游不保证新出口 IP；旧 TCP 会话不能迁移，断线由客户端重试。国家/节点数是接口即时快照，不保证不同时间/筛选条件下与 App 数值相同。全局网络或认证失败触发退避，配额满不自动删除未知实例。只回收本工具创建并登记的 client_id。
