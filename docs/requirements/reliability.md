# 网关远程使用与可靠性
status: final

用户要求：“还有以上报错，检测并修复；按照方案修复”，方案为功能检测报告的入口安全、远程网关、操作结果、自愈、常驻部署与可观测性。

目标：用户取消/重置管理连接不再抛出未处理 traceback，后续用户继续可用；远程模式提供真实可监听、需认证的 HTTP/SOCKS5 入口；失败操作诚实反馈；周期自愈与流量反馈闭环；提供安全、可验证的部署入口。

范围：代码、测试、配置范例、部署命令、架构和操作说明。保留现有用户配置/数据/未提交改动。远程模式需显式启用，旧网关保持本机模式；新远程网关强制代理认证，可配置来源 CIDR；磁盘秘密仅以受限文件权限持久化，不回传密码。

部署分界：修改机器已有防火墙/Nginx、证书、管理密码、重启服务须另行确认，已向用户询问；未批准前提供交付脚本并完成隔离部署验证，不把隔离验证称为手机运营商链路验证。该分界不缩小代码交付，真实 Android 网络问题要以重试日志定位，不以吞异常宣称网络已修复。
