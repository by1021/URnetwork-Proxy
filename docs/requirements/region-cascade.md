# 按国家自动选择可用地区

status: final
date: 2026-11-08

## 背景与目标

用户希望“选择指定地区后，先选国家，然后显示有的地区”，不输入搜索词。用户已确认国家 → 可用地区联动下拉方案并要求修改。

## 范围与不做

- Web 网关的地区模式：选择国家后自动列出官方当前返回的可用州／省／地区。
- 地区可刷新；切换国家清空旧选择；加载、失败、无供给和过期状态明确展示。
- 沿用官方位置 ID 和已有网关保存、代理创建逻辑，保留已有地区绑定的无关字段编辑。
- 国家模式与城市搜索保持原行为；不扩展为完整行政区数据库或城市级联。
- 不硬编码全部行政区，不自动退回全国或其他国家；不修改现有账户配置或代理资源。

## 用户视角验收

- 地区模式不显示地区搜索输入或搜索按钮；先选国家，再从自动加载的列表选择地区。
- 列表只包含所选国家且有官方供给的地区，保留真实 location_id。
- 更换国家、出口模式或关闭表单后，旧请求不会覆盖新选择，也不会卡住保存按钮。
- 加载失败／无可用地区时给出明确提示和刷新入口，不用旧国家或过期记录新建绑定。
- 编辑现有地区网关时保留当前绑定；暂时不可用时仍可保存未改变位置的其他字段。
- 国家选择、城市搜索、主备池位置绑定与既有网关操作不退化。

## 已确认取舍

列表以官方当前返回的供给为准，不是“某国全部行政区”。系统自动用所选国家的官方名称获取地区记录；用户不输入查询词。源接口仍为 `/network/find-provider-locations`。
